# 🌙 Arian World

Um site interativo onde você controla o **Arian**, um personagem de pixel art, usando comandos em português!

## 🎮 Como funciona

Digite comandos no chat e veja o Arian executar:
- 🚶 **Andar**: "ande", "caminhe", "passear"
- 🏃 **Correr**: "corra", "rápido", "voe"
- 🦘 **Pular**: "pule", "salte", "pinote"
- 💃 **Dançar**: "dance", "rebola", "festa"
- 🪑 **Sentar**: "sente", "descanse", "relaxa"
- 😴 **Dormir**: "durma", "cochile", "sono"
- 😂 **Rir**: "ria", "kkkk", "engraçado"
- 😢 **Chorar**: "chore", "triste", "snif"
- 🤔 **Pensar**: "pense", "hmmm", "duvida"
- 😱 **Assustar**: "assuste", "medo", "susto"

## 🛠️ Tecnologias

- **HTML5 Canvas** - Animações 2D e pixel art
- **CSS3** - Design responsivo e tema noturno
- **JavaScript Vanilla** - Lógica e interatividade
- **Sistema de Partículas** - Efeitos visuais no mouse/touch
- **Processamento de Linguagem Natural** - Reconhecimento de comandos em português
